**Respuesta corta.** Ctrl/⌘+O abre un archivo en cualquier momento. En un PDF: AvPág y RePág
pasan página, Ctrl/⌘+F busca, Ctrl/⌘+G va a una página, Ctrl/⌘+más, menos y 0 cambian el zoom.
F, T, R, Mayús+R y ? son atajos de una tecla que puedes desactivar. En Mac, ⌘ en lugar de Ctrl.

## Atajos generales

| Teclas | Acción |
|---|---|
| Ctrl/⌘ O | Abrir un archivo |
| Tab (primera vez) | «Saltar al contenido», directo al documento |
| Esc | Cerrar el diálogo abierto (Preferencias, ayuda, contraseña) |

## Atajos del visor PDF

| Teclas | Acción |
|---|---|
| AvPág · Espacio | Página siguiente |
| RePág · Mayús Espacio | Página anterior |
| → · ← | Página siguiente o anterior (en «Página a página») |
| ↓ · ↑ | Bajar o subir (en «Página a página», al borde pasa de página) |
| Inicio · Fin | Primera o última página |
| Ctrl/⌘ G | Ir al número de página |
| Ctrl/⌘ + · Ctrl/⌘ − | Acercar o alejar |
| Ctrl/⌘ 0 | Zoom al 100 % |
| Ctrl/⌘ F | Buscar en el documento |
| Intro · Mayús Intro | En la búsqueda: coincidencia siguiente o anterior |
| F3 · Mayús F3 | Con la búsqueda abierta: coincidencia siguiente o anterior |
| Esc | Cerrar la búsqueda, la ayuda o la pantalla completa |

## Atajos de una tecla (desactivables)

| Tecla | Acción |
|---|---|
| F | Entrar o salir de pantalla completa |
| T | Mostrar u ocultar las miniaturas |
| R | Girar 90° a la derecha |
| Mayús R | Girar 90° a la izquierda |
| ? | Abrir la ayuda de atajos |

Se desactivan en **Preferencias** → **Teclado**, por si chocan con tu lector de pantalla.

## Editor de Markdown y modo dividido

| Teclas | Acción |
|---|---|
| Ctrl/⌘ S | Guardar |
| Ctrl/⌘ Z · Ctrl/⌘ Mayús Z | Deshacer o rehacer |
| Tab | Sangrar (dentro del editor) |
| Esc y después Tab | Salir del editor con el teclado |
| ← · → (en el separador) | Mover el separador un 5 % |
| Inicio · Fin (en el separador) | Llevar el separador al mínimo o al máximo |

## Barras y paneles

- En la barra del visor, ← y → pasan de un botón a otro; Tab sale de la barra.
- En el panel de miniaturas, ↑ y ↓ mueven el foco e Intro o Espacio van a la página.
